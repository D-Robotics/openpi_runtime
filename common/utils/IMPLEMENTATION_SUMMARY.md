## 🎯 核心特性

### TopicTimeSynchronizer 类特性
1. **基准时间戳同步**: 选择一个话题作为基准，其他话题向其对齐
2. **实时数据获取**: 提供实时的同步数据接口
3. **线程安全**: 使用 `threading.RLock()` 确保安全访问
4. **自动缓冲区管理**: 防止内存溢出，自动清理旧数据
5. **详细统计信息**: 包含同步成功率、时间偏移等指标
6. **灵活配置**: 支持自定义同步窗口、缓冲区大小等参数

### 同步算法
- **策略**: 基准时间戳同步（策略1）
- **时间窗口**: 默认50ms，可配置
- **基准选择**: 默认第一个话题，可自定义
- **容错处理**: 超出时间窗口的消息将被丢弃

## 🚀 使用方法

### 基本使用
```python
from common.utils.topic_time_synchronizer import TopicTimeSynchronizer

# 初始化
sync = TopicTimeSynchronizer(
    topics=["cam_high", "cam_left_wrist", "qpos"],
    reference_topic="cam_high",
    sync_window_ms=50.0
)

# 添加消息
sync.add_message("cam_high", image_data, timestamp_ns)
sync.add_message("cam_left_wrist", image_data, timestamp_ns)
sync.add_message("qpos", qpos_data, timestamp_ns)

# 获取同步数据
synced_data = sync.get_synced_data(max_age_ms=100)
```
